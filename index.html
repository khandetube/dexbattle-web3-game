03 / SECURITY

Security is part of the UX.

The prototype surfaces the boundaries that matter before real funds ever touch production contracts.

01

Reentrancy defense

Withdrawal flow clears credit before the external call and is designed for a non-reentrant guard.

02

State validation

Match transitions validate state, participants and exact entry amounts.

03

Trust boundary

Frontend state is never treated as proof of a game result; settlement requires verifiable authority.

04

Failure handling

Rejected signatures, RPC errors and pending confirmations are first-class UI states.
